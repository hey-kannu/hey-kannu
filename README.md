An IoT-enabled smart helmet designed to monitor **worker health and environmental safety**.

**Core technologies**

`ESP32/MCU` · `MAX30102` · `MPU6050` · `Temperature` · `Gas Sensors` · `GPS` · `GSM/LoRa`

Features include:

* ❤️ Heart-rate & SpO₂ monitoring
* 🌡️ Temperature monitoring
* 🫁 Environmental monitoring
* 🧍 Fall detection

* 🚨 Hazard detection
* 📡 Wireless communication
